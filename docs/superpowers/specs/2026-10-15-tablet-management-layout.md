# 平板管理页面适配

用户已选择第一张横屏方案，并认可对应竖屏效果图。

## 范围

- 保持 Java 原生 Android UI、系统明暗主题及中英文资源。
- 平板横屏采用左侧管理分类导航，右侧内容可独立滚动；竖屏将分类收成顶部横向导航。
- 进入平板管理页直接显示媒体库维护，保留刮削、匹配、任务入口；子详情返回所属分类，顶层返回设置。
- 维护页采用分组目录列表。横屏独立显示最近扫描列；竖屏放在路径下方。更新操作横屏并列、竖屏上下排列。
- 手机及窄分屏保持现有页面，不改变服务器 API、写入确认、防重复提交、任务监测、播放器及本地数据格式。
- 页面恢复继续使用现有 route、筛选、分页和滚动保存逻辑；导航选中状态随 route 同步。

## 适配规则

当前窗口宽度和最小宽度均至少 600dp 才使用平板布局；横屏且宽度至少 960dp 使用侧栏，其他平板窗口使用顶部导航。窄分屏回退原手机布局。

## 验收

JVM 回归、lint、release 构建通过。小米平板 5 Pro 进行横竖屏导航、维护列表、刮削与匹配只读页面、旋转恢复和返回检查；安装使用原签名与 `install -r`。不触发真实服务器写入任务。恢复设备原始设置。完成后提供候选 APK 和本地验证记录，不推送或发布。
